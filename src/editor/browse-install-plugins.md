# Browse and Install Plugins

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Basic" />

The **Browse and Install Plugins** panel allows users to discover, browse, and install Elementor addons directly from within [the editor](./../editor/). This provides a seamless experience for extending Elementor's functionality without leaving the page builder.

## Overview

This panel integrates plugin discovery into the Elementor workflow, making it easy for users to find and install addons that add new widgets, features, and functionality to their sites.

## Structure and Functionality

The panel provides the following capabilities:

* **Browse Plugins** - Explore available Elementor addons from the marketplace.
* **Search** - Find specific plugins by name, functionality, or category.
* **Install** - Install addons directly without navigating to the WordPress plugins screen.
* **Plugin Details** - View information about each addon including description, ratings, and compatibility.

## Accessing the Panel

Users can access the Browse and Install Plugins panel from the [Menu Panel](./menu-panel/) in the editor sidebar.

## For Addon Developers

If you're developing an Elementor addon and want to make it discoverable through this panel, ensure your addon follows the [Elementor addon standards](./../addons/) and is properly listed in the marketplace.

Key requirements for addon visibility:

* Proper [plugin header comments](./../addons/plugin-header/) including Elementor compatibility information.
* Following WordPress and Elementor [coding standards](./../addons/).
* Clear documentation and description of your addon's features.
